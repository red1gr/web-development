## OVERVIEW

THIS PROJECT IS A SOPHISTICATED PERSONAL PORTFOLIO APPLICATION CRAFTED TO DELIVER HIGH-END DIGITAL EXPERIENCES. IT LEVERAGES CUTTING-EDGE FRONTEND TECHNOLOGIES TO CREATE A DYNAMIC, ANIMATED USER INTERFACE THAT STANDS OUT. A CORE FEATURE OF THIS PORTFOLIO IS ITS REAL-TIME INTEGRATION WITH DISCORD THROUGH THE LANYARD API, ALLOWING VISITORS TO SEE THE OWNER'S LIVE DISCORD STATUS AND ACTIVITIES DIRECTLY ON THE WEBSITE. DESIGNED FOR DEVELOPERS AND CREATIVES ALIKE, IT SERVES AS A SHOWCASE FOR ADVANCED UI/UX DEVELOPMENT, SMOOTH ANIMATIONS, AND INTERACTIVE WEB CAPABILITIES.

## FEATURES

- **HIGH-FIDELITY USER INTERFACE**: CRAFTED WITH REACT AND TYPESCRIPT FOR A ROBUST, MODULAR, AND SCALABLE FRONTEND.
- **ADVANCED ANIMATIONS & TRANSITIONS**: SMOOTH, CAPTIVATING ANIMATIONS POWERED BY GSAP AND FRAMER MOTION, ENHANCING USER ENGAGEMENT.
- **INTERACTIVE 3D GRAPHICS**: INTEGRATES `@REACT-THREE/FIBER` AND `@SPLINETOOL/RUNTIME` FOR IMMERSIVE 3D MODELS AND SCENES WITHIN THE UI.
- **REAL-TIME DISCORD STATUS**: DISPLAYS LIVE DISCORD ACTIVITIES AND PRESENCE USING THE LANYARD API FOR DYNAMIC CONTENT.
- **UTILITY-FIRST STYLING**: STYLED EFFICIENTLY WITH TAILWIND CSS FOR RAPID AND CONSISTENT UI DEVELOPMENT.
- **OPTIMIZED DATA FETCHING**: UTILIZES TANSTACK QUERY FOR EFFICIENT DATA MANAGEMENT, CACHING, AND SYNCHRONIZATION, ENSURING A PERFORMANT EXPERIENCE.
- **RESPONSIVE DESIGN**: ADAPTS SEAMLESSLY ACROSS VARIOUS DEVICES AND SCREEN SIZES (INFERRED FROM MODERN WEB PRACTICES WITH TAILWIND).
- **DEVELOPER EXPERIENCE**: ENHANCED WITH ESLINT AND PRETTIER FOR MAINTAINING HIGH CODE QUALITY AND CONSISTENCY.

## QUICK START

FOLLOW THESE STEPS TO GET A DEVELOPMENT ENVIRONMENT RUNNING ON YOUR LOCAL MACHINE.

### PREREQUISITES
- NODE.JS (V18 OR HIGHER RECOMMENDED)
- A PACKAGE MANAGER: `NPM` (COMES WITH NODE.JS) OR `BUN` (IF PREFERRED, INSTALL SEPARATELY)

### INSTALLATION

1.  **CLONE THE REPOSITORY**
    ```bash
    git clone https://github.com/red1gr/discord_portfolio.git
    cd discord_portfolio
    ```

2.  **INSTALL DEPENDENCIES**
    CHOOSE YOUR PREFERRED PACKAGE MANAGER:
    ```bash
    # USING NPM
    npm install

    # OR USING BUN
    bun install
    ```

3.  **ENVIRONMENT SETUP**
    THIS PROJECT PRIMARILY RELIES ON CLIENT-SIDE FETCHING FOR THE LANYARD API. IF YOU NEED TO SPECIFY A DISCORD USER ID OR OTHER PUBLIC ENVIRONMENT VARIABLES, YOU MIGHT USE A `.ENV` FILE (E.G., `.ENV.LOCAL` FOR VITE). CREATE A `.ENV.LOCAL` FILE IN THE PROJECT ROOT IF NEEDED:
    ```bash
    cp .env.example .env.local # IF A .ENV.EXAMPLE EXISTED, OTHERWISE CREATE MANUALLY
    ```
    THEN, CONFIGURE YOUR ENVIRONMENT VARIABLES:
    ```
    VITE_PUBLIC_DISCORD_USER_ID="YOUR_DISCORD_USER_ID"
    # REPLACE WITH YOUR ACTUAL DISCORD USER ID FOR LANYARD API INTEGRATION.
    # NOTE: LANYARD API IS OFTEN USED DIRECTLY IN THE FRONTEND, SO THIS MIGHT BE OPTIONAL OR HARDCODED.
    ```
    *IF NO SPECIFIC ENVIRONMENT VARIABLES ARE REQUIRED, YOU CAN SKIP THIS STEP.*

4.  **START DEVELOPMENT SERVER**
    ```bash
    # USING NPM
    npm run dev

    # OR USING BUN
    bun dev
    ```

5.  **OPEN YOUR BROWSER**
    VISIT `http://localhost:5173` (OR THE PORT DISPLAYED IN YOUR TERMINAL).


### CONFIGURATION FILES
-   `vite.config.ts`: CONFIGURES VITE, INCLUDING REACT PLUGIN AND TYPESCRIPT SETTINGS.
-   `tailwind.config.js`: DEFINES TAILWIND CSS CUSTOMIZATIONS (COLORS, FONTS, PLUGINS).
-   `postcss.config.js`: CONFIGURES POSTCSS PLUGINS, INCLUDING TAILWIND CSS AND AUTOPREFIXER.
-   `eslint.config.js`: MANAGES CODE LINTING RULES FOR TYPESCRIPT AND REACT.
-   `.prettierrc`: ENSURES CONSISTENT CODE FORMATTING ACROSS THE PROJECT.
-   `tsconfig.json`, `tsconfig.app.json`, `tsconfig.node.json`: TYPESCRIPT COMPILER CONFIGURATIONS FOR DIFFERENT CONTEXTS.

## DEVELOPMENT



### DEVELOPMENT WORKFLOW
1.  RUN `npm install` OR `bun install` TO SET UP.
2.  USE `npm run dev` OR `bun dev` TO START THE DEVELOPMENT SERVER, WHICH INCLUDES HOT MODULE REPLACEMENT (HMR) FOR A FAST DEVELOPMENT LOOP.

## DEPLOYMENT

### PRODUCTION BUILD
TO CREATE AN OPTIMIZED PRODUCTION BUILD OF THE APPLICATION:
```bash

# USING NPM
npm run build

# OR USING BUN
bun build
```
THIS COMMAND WILL COMPILE THE APPLICATION INTO THE `dist/` DIRECTORY, READY FOR DEPLOYMENT.

### DEPLOYMENT OPTIONS
THE `dist` FOLDER GENERATED BY THE BUILD PROCESS CONTAINS ALL THE STATIC ASSETS REQUIRED TO DEPLOY THE APPLICATION.
-   **STATIC HOSTING:** SERVICES LIKE VERCEL, NETLIFY, GITHUB PAGES, OR CLOUDFLARE PAGES ARE IDEAL FOR DEPLOYING THIS FRONTEND-ONLY APPLICATION. SIMPLY POINT THEM TO THE `dist` DIRECTORY.
-   **DOCKER:** WHILE NOT EXPLICITLY CONFIGURED, A `Dockerfile` COULD BE ADDED TO CONTAINERIZE THE APPLICATION FOR MORE COMPLEX DEPLOYMENT SCENARIOS OR INTEGRATION INTO LARGER SYSTEMS.
